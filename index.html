Buildings

Set how many of each building you have (0 means you haven't built it). Full-time worker buildings need one Aniimo working in them the whole time. Part-time farm work (Farmland and Woodland plots) only needs help now and then – loosening soil, planting, watering and harvesting – so a few Aniimo can look after many plots.

About the data

The planner uses free fan-made references that are built from the game's own files, plus a few corrections checked in-game by players. After a game update some numbers may be out of date until the data is refreshed.
